# Linux Services Manager 🛠️

Интерактивный Bash-скрипт для удобного мониторинга и управления системными и пользовательскими службами через `systemctl` в Linux (отлично работает на Arch Linux).

Скрипт автоматически разделяет права: системные службы (сеть, bluetooth) управляются через `sudo`, а пользовательские (PipeWire, WirePlumber) — напрямую от текущего пользователя, без постоянного запроса пароля.

## Функционал
* 📊 Отображение текущего статуса служб в реальном времени (включен/выключен).
* 🔄 Быстрый перезапуск (restart), запуск (start) и остановка (stop) через текстовое меню.
* 🎧 Корректная работа со звуковыми службами PipeWire на уровне пользователя (`--user`).
* 📋 Легко настраиваемый список отслеживаемых процессов.

## Список служб по умолчанию
* `NetworkManager` (Интернет)
* `pipewire` / `pipewire-pulse` / `wireplumber` (Звуковая подсистема)
* `bluetooth` (Беспроводные устройства)
* `sshd` (Удаленный доступ)
* `systemd-journald` (Системные логи)

## Установка и запуск

1. Клонируйте репозиторий или скачайте скрипт:
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

2. Сделайте скрипт исполняемым:
```bash
chmod +x sysmanager.sh
```

3. Запустите:
```bash
./sysmanager.sh
```

## Как добавить свои службы?
Откройте скрипт в любом текстовом редакторе и найдите вторую строчку:
```bash
SERVICES=("NetworkManager" "pipewire" "..." "ваша_служба")
```
Просто впишите имя нужной службы через пробел внутрь скобок.
