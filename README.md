# linux-services-manager
Linux Services Manager — это легкий интерактивный Bash-скрипт, предназначенный для быстрого мониторинга и управления системными и пользовательскими службами через systemctl. Скрипт изначально оптимизирован для работы в современных дистрибутивах Linux, включая Arch Linux, где критически важно разделять контексты выполнения процессов.
